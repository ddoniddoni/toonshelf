# 01. 제품 명세

기준일: 2026-10-01. 이 문서의 수치, 제한, 추천 방식은 **초기 제품 설계값**이다. 실제 이용 현황이나 법률상 필수 기준을 주장하는 수치가 아니다.

## 1. 제품 정의

**여러 플랫폼에서 본 웹툰을 내 취향의 기록으로 모으고, 리뷰와 티어리스트를 통해 다른 독자와 공유하는 서비스.**

핵심 순환은 `작품 발견 → 내 서재 저장 → 읽기 상태/평가 기록 → 리뷰/티어 공유 → 취향이 비슷한 독자 발견 → 새 작품 발견`이다. 공식 플랫폼으로 독자를 연결하되 원문 이미지나 회차를 재제공하지 않는다.

첫 사용자는 1인 개발자의 지인 테스트와 소규모 공개 베타를 가정한다. 한국어 UI가 기본이며 날짜는 DB에서 UTC, 화면에서는 사용자 시간대에 따라 표시한다. 기본 시간대는 Asia/Seoul이다.

## 2. 권한 역할

| 역할 | 할 수 있는 것 |
|---|---|
| 비회원 | 공개 작품/리뷰/티어/게시글/프로필 열람, 검색, 공식 작품 링크 이동 |
| 이메일 인증 전 회원 | 인증 재발송, 계정 확인, 로그아웃. 커뮤니티 쓰기는 제한 |
| 온보딩 완료 회원 | 자신의 서재/평가/티어 관리, 리뷰, 글, 댓글, 좋아요, 팔로우, 비교 |
| 운영자 moderator | 신고 검토, 콘텐츠 숨김과 복구, 정책 위반 처리 |
| 관리자 admin | 운영자 기능, 작품/플랫폼/장르/권리 등록, 계정 정지, 관리 감사 기록 |

정지 중인 회원은 새 콘텐츠나 반응을 만들 수 없다. 삭제 처리 중인 회원의 공개 콘텐츠는 즉시 숨긴다. 관리자 권한 부여는 서버 관리 절차로만 하며 일반 관리자 화면에서 자신을 승격할 수 없다.

| RATE-04 | 독서 통계 | 읽은 작품 수, 상태별 수, 별점/티어 분포, 선호 장르 |

`나중에 볼 작품`에는 별점과 기본 티어를 저장하지 않는다. 평가하려면 읽기 상태를 먼저 선택한다. 서재 삭제로 평가가 함께 삭제되는 경우 확인창에 범위를 보여준다. 별도 작성한 리뷰나 티어표까지 조용히 삭제하지 않는다.

`완독`은 사용자의 독서 완료 기록이다. 작품 자체의 연재 완료와 동일한 필드가 아니다. 연재 중 작품에 완독 표시를 할 때 이 차이를 안내한다. 본 작품 수는 보는 중/완독/중도하차를 포함하고 예정 작품은 제외한다.

**커뮤니티 글 증분 · 2026-10-08 (코드·migration 작성, DB 미적용/실행 미검증):** COM-01/02의 네 주제와 최대 5개 공개 작품 연결, COM-03의 주제/작품/제목·본문 검색·최신순, COM-04의 비공개 초안/게시본 분리·수정·공개 취소·삭제·스포일러를 작성했다. SOC-03 글 피드와 SOC-06 차단, OPS-01/02/04 신고·운영 숨김/복구·감사·속도 제한을 함께 작성했다. MCP 인증 갱신 오류로 새 SQL은 원격 미적용이다. 좋아요·댓글·인기순·관련 알림과 모든 실행 검수는 후속이며 COM/P5 전체를 완료로 체크하지 않는다.

리뷰/글/댓글은 기본 plain text다. HTML 입력은 실행하지 않으며 임의 iframe, 이미지, 스크립트를 지원하지 않는다. 본문 URL은 검증된 HTTP(S) 링크로만 렌더링하고 외부 이동임을 표시한다. 불법 복제 서비스 링크, 개인정보 노출, 괴롭힘에 대한 신고 사유를 제공한다.

리뷰에서 직접 입력한 읽은 기준 회차는 사용자가 게시하는 정보다. 개인 서재의 비공개 회차를 리뷰로 자동 복사하지 않는다.

리뷰에는 개인 평가가 공개되어 있을 때만 현재 별점을 붙인다. 비공개 별점을 리뷰에 몰래 표시하지 않는다. 별점 없이 리뷰를 게시하는 것도 가능하다.

사용자당 기본 상한은 티어표 50개, 표당 작품 300개, 행 2-10개다. 기본 6개 행은 S/A/B/C/D/F다. 행 삭제 시 작품은 미배치함으로 이동하며 삭제되지 않는다. 미배치 작품은 공개 게시본에서 제외한다.

자동 저장은 개인 초안에만 반영한다. 방문자가 보는 게시본은 `게시/게시본 업데이트`를 눌렀을 때만 교체한다. 게시본은 DB에 저장되고 새로고침 후에도 같은 내용으로 조회되어야 한다.

티어표 행을 수정해도 개인 기본 티어는 자동 변경하지 않는다. `이 표의 티어를 내 기본 평가에 반영`은 표준 코드가 유지된 행만 대상으로 변경 미리보기와 확인을 거친다. 사용자 지정 행의 이름을 보고 S/A 등을 추정하지 않는다.

**공개 티어 댓글 첫 증분 · 2026-10-05 (작성·실행 미검증):** TIER-10의 public 표 댓글·한 단계 답글/본인 수정·삭제와 SOC-06 차단, OPS-01/04 신고·운영 hide/restore·회원 제한 코드를 작성했다. 최초 스포일러 원문은 tier/원 댓글/개별 댓글 중 하나라도 해당하면 제외한다. private/unlisted/숨김/삭제 상태는 현재 권한에서 거절하며 본인 본문 삭제만 토론 접근과 별도로 허용한다. 댓글 가중 인기 공식·팔로우와 리뷰/글 댓글·알림은 후속이다. 테스트/DB 적용/사용자 흐름은 미검증이고 TIER-10 및 P4/P5 전체를 완료로 체크하지 않는다.

**공개 티어 인기순 증분 · 2026-10-07 (코드·DB 반영, 실행 검수 대기):** TIER-10의 인기 정렬을 최근 7일 유효 좋아요 수 + 서로 다른 댓글 참여자 수 × 2로 작성했다. 같은 사람의 원 댓글·답글은 한 명이며 수정 시각으로 기간을 갱신하지 않는다. 현재 공개/댓글 접근/계정 상태를 검사하고 본인·삭제·숨김·차단 반응은 제외한다. 카드에 최근 참여 수와 점수·정렬 기준을 표시한다. 팔로우·리뷰/글 인기와 전체 P4/P5 완료는 후속이며 요구사항 완료 체크는 유지한다.

## 4. 공개 범위의 의미

| 데이터 | 초기값 | 공개 방식 |
|---|---|---|
| 기본 프로필 | 온보딩 완료 후 공개 | username, 닉네임, 소개, 아바타만 |
| 이메일, 동의, 설정 | 비공개 | 본인과 제한된 운영 기능만 |
| 서재 항목 | 비공개 | 작품과 읽기 상태를 항목별 공개 |
| 읽은 회차, 메모, 개인 태그 | 항상 비공개 | 공개 서재에도 포함하지 않음 |
| 별점과 기본 티어 | 비공개 | 서재 공개와 별도로 공개 |
| 리뷰/게시글 | 초안 비공개 | 사용자가 게시하면 공개 |
| 티어 초안 | 항상 비공개 | 작성자만 편집/열람 |
| 티어 게시본 | 비공개로 시작 | 공개/링크 공개를 선택해 게시 |

공개 서재를 저장한 방문자에게 타인의 별점, 티어, 회차, 메모는 복사하지 않는다. 자기 서재에 나중에 볼 작품으로 추가한다.

`모든 서재와 평가 비공개`는 기존 서재 항목과 개인 평가의 공개 여부 및 앞으로의 기본값을 바꾼다. 이미 게시한 리뷰, 글, 티어표는 별도의 공개 콘텐츠라는 사실과 일괄 게시 취소 기능을 명시한다.

링크로만 공개한 티어표는 URL을 가진 누구나 볼 수 있다. 보안이 필요한 개인 자료는 비공개를 사용하도록 안내한다. 비공개 전환 이후에도 이미 내려받은 PNG나 타인이 복사한 내용까지 회수할 수는 없다.

## 5. 이미지와 데이터 수집 원칙

초기 버전은 허가 없는 표지를 전혀 요구하지 않는다. 작품 제목을 담은 자체 타이포그래피 카드와 색상/기하 패턴으로 모든 화면과 공유 이미지를 구현한다. 그림을 복제하거나 원작 그림체를 재현해 대체하지 않는다.

이미지 등록에는 권리자, 허가 근거, 허가 범위, 만료일, 출처 표시 문구를 기록한다. 작은 썸네일, 출처 표시, 공식 페이지 연결만으로 사용 권한을 가정하지 않는다. 작품명 등 사실 정보도 자동 대량 수집을 기본값으로 삼지 않으며 출처를 검증한 수동 등록부터 시작한다.

공식 로고 대신 플랫폼명을 텍스트로 표시한다. 운영자가 직접 작성한 설명만 저장한다. 서비스 약관과 권리 검토 없이 플랫폼 내부 API, 비공식 래퍼, Open Graph 이미지 자동 수집, 사용자 업로드 표지 우회 기능을 넣지 않는다.

## 6. 이번 범위 밖

원문/유료 회차 뷰어, 불법 링크 탐색, 플랫폼 계정 비밀번호 수집, 기존 관심웹툰 무단 가져오기, 결제/포인트, 광고 시스템, 작가 정산, 실시간 채팅과 DM, 네이티브 앱, 자동 번역, LLM 유료 API 기반 추천은 제외한다.

성인 작품 데이터는 스키마에서 식별 가능해야 하지만 공개 출시 때 기본 비활성화한다. 청소년 접근 제한과 운영 책임에 관한 별도 검토 없이 단순 체크박스를 실제 연령 확인으로 취급하지 않는다. 탑툰을 지원 플랫폼으로 등록하는 것과 모든 성인 작품을 노출하는 것은 별개다.
