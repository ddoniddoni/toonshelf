홈 배너 오른쪽은 시안처럼 이미지 영역과 하단 설명으로 나눴다. 시안의 배너 일러스트를 가져오는 요청은 자동 승인 검토에서 예시 이미지 사용 허가가 불명확하다는 이유로 거절돼 별도 승인 대기다. 현재는 허가된 카탈로그 표지 또는 직접 만든 T 문자를 표시한다. 이 일러스트에 대한 화면 표시 승인을 받더라도 작품 표지 데이터·PNG/OG 재배포 권한으로 확대하지 않는다.

홈의 최근 등록 작품은 기존 공개 카탈로그 조회를 사용하고 리뷰는 그중 첫 작품의 공개 리뷰로 표시한다. 전체 서비스의 인기 순위·최신 리뷰라고 표시하지 않는다. 조회 실패/미연결/빈 상태에 예시 작품이나 가짜 통계를 넣지 않는다. 서재는 기본 카드 보기이며 처음에는 현재 페이지에서 공개 메타데이터가 있는 첫 본인 기록을 오른쪽에 연다. `?edit=작품UUID`는 현재 페이지의 본인 기록만 선택하고 `?edit=none`은 선택을 해제한다. 숨긴 작품은 작품 정보를 제공하지 않고 기존 본인 기록 화면을 안내한다. 패널 저장은 기존 action을 사용해 `/me/library/[workId]`로 이동한다. 상세의 같은 장르 작품은 첫 장르의 최근 등록순 조회이며 취향 추천 알고리즘은 구현하지 않았다.

`/tiers`는 현재 배치 미리 보기다. 저장·PNG 버튼은 비활성이고 작품 추가·드래그·자동 저장·공개·공유를 구현하지 않았다. 아래 URL/티어 흐름은 최종 제품 설계를 유지한다. 이번 변경의 실제 화면·반응형·테마·접근성·저장 흐름과 자동 검사는 모두 미실행이다.

### P3 공개 서재 검색·필터 작성 상태 · 2026-10-03

공개 프로필에서 `공개 서재 검색·필터`로 `/u/[username]/library`에 이동한다. GET 폼에서 제목·별칭·작가, 공개 읽기 상태, 플랫폼, 장르, 정확한 공개 별점, 공개 기본 티어를 조합한다. 제목순·공개 별점 높은 순·공개 티어 S→F 순으로 정렬하며 미공개/미지정 평가는 마지막에 놓고 공개 작품명·UUID로 동률을 정리한다. 비공개 개인 활동 시각으로 정렬하지 않는다. 조건을 적용하면 첫 페이지로 이동하고 이전/다음 링크는 모든 조건을 보존한다. 24개씩 최대 1000페이지이며 빈 결과/빈 페이지/잘못된 조건에는 초기화나 첫 페이지 이동을 제공한다.

읽기 상태와 평가는 독립적으로 공개된 값만 사용한다. 상태 비공개·평가 공개 작품은 상태 조건에 일치하지 않고, 상태 공개·평가 비공개 작품은 별점/티어 조건에 일치하지 않는다. 공개 endpoint는 본인이 열어도 비공개 기록을 포함하지 않는다. 개인 태그·메모·회차·날짜는 필터를 제공하지 않는다. 차단 관계·정지/미완성 회원·숨김/성인/미확인 작품은 기존 가시성 기준을 따른다. 실제 화면·필터·페이지 이동·저장·모바일·키보드·DB 흐름은 미확인이다.

### P3 서재·평가 작성 상태 · 2026-10-02

작품 상세에서 내 독서 기록을 작성하고 `/me/library`에서 검색·필터·정렬·목록/카드·24개 단위 페이지·선택 일괄 변경을 제공하는 코드를 작성했다. `/me/library/[workId]`에서 상태/별점/기본 티어와 본인 전용 회차/날짜/메모/태그/선호 플랫폼을 편집한다. 서재 공개와 평가 공개를 각각 설명하고 planned 변경 시 평가 삭제 동의를 요구한다. 공개 프로필은 상태와 평가를 독립적으로 표시하고 내 서재로 가져오는 버튼을 제공한다. 설정·서재의 전체 비공개 동작은 기존 기록·평가·기본값을 함께 변경한다. DB·브라우저 실행은 미검증이며 리뷰 작성 상태는 아래에 기록했다.

### P3 리뷰·안전 기능 작성 상태 · 2026-10-02

`/me/reviews/[id]/edit`는 수동 초안 저장과 저장된 초안의 게시를 분리한다. 게시할 내용과 스포일러/공개 기준 회차를 미리 보여주고 확인을 받는다. 다른 탭의 저장/게시 충돌은 안전한 오류로 안내한다. 공개 취소와 삭제는 각각 확인을 요구하며 운영 숨김 상태에서는 게시를 허용하지 않는다. 숨긴 작품의 기존 개인 초안은 본인만 읽고 공개 취소·삭제할 수 있다.

공개 리뷰 상세·작품별/작성자별 목록은 12개씩 첫 게시 최신순이며 좋아요순은 P5 준비 안내다. 스포일러 리뷰는 처음에 본문을 전달하지 않고 펼치기를 눌러 현재 게시 version·차단·공개 조건을 다시 확인한다. 메타데이터는 작품명과 일반 안내만 사용한다. 본문은 plain text로 표시하고 비공개 진행 회차를 공개 기준 회차에 복사하지 않는다. 활성 회원은 작품 가져오기, 신고, 차단을 사용할 수 있다.

`/me/reports`는 내 신고·처리 결과, `/settings/blocks`는 내 차단/해제 목록이다. `/admin/reports`·`/admin/reviews/[id]`는 실제 DB moderator/admin 역할로 제한하며 원문 확인도 별도 버튼을 사용한다. 비공개 편집 초안은 운영 검토 화면에 제공하지 않는다. 위 동작의 실제 UI·모바일·접근성·DB 실행 검수와 자동 검사는 모두 미실행이다.

한국어 우선, 모바일 우선의 기록형 서비스다. 직접 만든 텍스트 표지를 기본으로 사용하고 검색·기록·티어 공유로 이어지는 경로를 제공한다. 홈 배너는 서비스의 읽기·기록·공유 개념을 보여준다.

라이트/다크/시스템 테마를 지원하며 헤더의 테마 메뉴에서 선택한다. 화면 치수와 폰트는 위 Stitch 기준을 따른다. 색상은 CSS 변수로 관리하고 기본 간격은 4/8/12/16/24/32px다. 본문 대비와 포커스 검수는 사용자 요청 후 진행한다.

공통 컴포넌트: AppHeader, MobileNavigation, WorkCard, TypographyCover, PlatformBadge, StarRatingInput, TierBadge, LibraryStateButton, VisibilitySelector, SpoilerGate, EmptyState, InlineError, LoadingSkeleton, ConfirmDialog, ReportDialog, CursorPagination, UserAvatar, SaveStatus, Toast.

작품 카드에는 제목, 플랫폼명, 작가, 장르를 배치하고 실제 평가·개인 기록이 제공되는 영역에만 그 값을 표시한다. 비회원에게 개인 상태 조회를 하지 않는다. 표지 비율은 3:4로 고정하고 제목은 카드 아래에 표시하며 링크의 접근성 이름은 전체 제목을 유지한다.

## 2. 탐색 구조

현재 데스크톱 상단: 로고, 검색, 홈, 요일별 웹툰, 작품 탐색, 실시간 순위, 독자 티어리스트, 내 서재, 테마, 알림, 실제 계정 프로필. 요일 메뉴는 홈의 해당 영역으로 이동하고 실시간 순위는 준비 안내다. 알림은 P5 구현 전 비활성이며 새 티어 생성·커뮤니티는 후속 기능이다.

모바일 하단: 홈, 탐색, 내 서재, 티어, 내 프로필. 커뮤니티와 알림은 상단에 배치한다. 비회원이 내 서재를 누르면 로그인 안내 후 원래 목적지를 보존한다.

## 3. URL과 권한

| `/admin/users` | 계정 상태 관리 | 관리자 |
| `/admin/audit` | 관리 이력 | 관리자 |
| `/legal/terms` | 이용약관 | 공개, 실제 운영 정보 확정 필요 |
| `/legal/privacy` | 개인정보 처리 안내 | 공개, 실제 운영 정보 확정 필요 |
| `/legal/content-policy` | 게시물/스포일러/권리 정책 | 공개 |
| `/legal/copyright` | 권리자 신고 안내 | 공개, 작동하는 연락 경로 |

Next.js에서 같은 세그먼트에 `page.tsx`와 `route.ts`를 함께 두지 않는다. `/auth/confirm`은 페이지와 Server Action으로 처리하고 `/auth/callback`만 Route Handler로 사용한다.

## 4. 주요 화면 상세

### P1 실제 경로 구성 · 2026-10-02

인증/온보딩/프로필/계정/공개 범위·알림/공개 프로필 페이지와 Server Actions를 작성했다. `/auth/account-status`는 정지·삭제 중 계정 안내이며 `/auth/callback`만 Route Handler다. `/settings/notifications`는 `/settings/privacy`와 같은 설정 폼을 제공한다. 연결이 없으면 입력 가능한 가짜 폼 대신 연결 준비 안내를 표시한다. 로그인 전 회원 경로는 안전하게 검증한 returnTo를 보존한다. 실제 인증·저장·모바일·접근성 흐름은 이번 작업에서 미검증이다.

법적 안내 경로는 개발 미리 보기 버전임을 표시하고 원격 신규 가입은 앱에서 기본 비활성화한다. 아바타는 공개 파일임을 업로드 전에 표시한다. 탈퇴·데이터 내보내기는 P7 운영 작업을 구현하기 전까지 비활성 안내만 제공한다.

### P2 작성 경로 · 2026-10-02

`/explore`와 `/works/[slug]`, `/submissions/new`·`/submissions`, 카탈로그 관리용 `/admin`·`/admin/works`·`/admin/works/new`·`/admin/works/[id]/edit`·`/admin/works/merge`·`/admin/submissions`·`/admin/assets`·`/admin/audit`를 작성했다. 관리 경로는 verified/active/admin 계정만 사용하며 미설정 상태에는 연결 준비 안내를 제공한다. 일반 회원은 본인 제보와 처리 결과만 본다.

검색은 제목·별칭·작가명에 포함된 문자열을 대상으로 하며 초성·형태소·오타 유사 검색은 제공한다고 표시하지 않는다. 필터는 반복 URL 파라미터로 보존하고 같은 공식 링크에 플랫폼/요일을 함께 적용한다. 350ms 자동완성과 키보드로 접근 가능한 작품 링크를 작성했다. 평점순·평가·리뷰·개인 서재 상태는 P3에서 연결하며 현재 가짜 수치나 동작을 표시하지 않는다.

표시 허가가 유효한 이미지 요청에 실패하면 텍스트 표지로 돌아간다. 병합은 결과/버전/표지 철회/남길 상태를 먼저 보여주며 확인과 사유를 요구한다. 제보 결과는 내 제보 화면에서 확인하고 알림 채널은 P5에서 연결한다. 이 화면들의 실제 브라우저·모바일·키보드·접근성 검수는 미실행이다.

### 홈

비회원: 서비스 한 문장 소개, 작품 검색, 최근 공개 티어, 최근 리뷰, 회원가입 유도. 회원: 최근 기록한 작품, 바로 이어서 편집할 티어, 팔로우 소식, 근거가 있는 추천. 빈 DB에서 가짜 인기 작품을 만들지 않고 첫 작품 제보와 사용법을 안내한다.

### 작품 탐색

검색창과 결과 수, 활성 필터 칩, 필터 초기화, 정렬, 작품 그리드를 제공한다. URL searchParams에 `q`, `platform`, `genre`, `status`, `day`, `sort`를 저장하여 뒤로 가기와 링크 공유를 지원한다. 다중 값은 반복 파라미터로 전달하고 서버에서 허용값을 검증한다.

한/두 글자 검색은 지원하되 결과 수와 요청 빈도를 제한한다. 초성 검색과 전문 형태소 분석을 제공한다고 표시하지 않는다. 오타 유사 검색과 별칭 검색의 범위를 명시한다.

### 작품 상세

상단: 자체 표지 또는 허가된 표지, 제목과 별칭, 작가/원작/그림 역할, 장르, 연재 상태, 플랫폼별 공식 링크. 중단: 내 서재 상태, 별점, 기본 티어, 평가 공개 범위. 하단: 사이트 전체 평점, 티어 분포, 독서 상태 조건별 평점, 리뷰, 이 작품을 좋아한 독자가 평가한 다른 작품.

외부 플랫폼의 평점과 이 서비스에서 모은 평점을 혼동하지 않도록 `ToonShelf 회원 평가`라고 표시한다. 플랫폼별 가격, 무료 회차 수, 실시간 연재 일정은 검증된 입력이 없는 한 표시하지 않는다.

`리뷰 쓰기`는 비회원에게 로그인 후 작품 페이지로 복귀하게 한다. 표본이 없으면 별점 0.0 대신 `아직 평가가 없어요`를 표시한다. 성인/숨김 작품은 상세 URL을 직접 열어도 일반 방문자에게 데이터가 나오지 않는다.

### 내 서재

보는 중/완독/중도하차/나중에 탭, 제목 검색, 태그, 장르, 플랫폼, 별점, 기본 티어 필터, 카드/목록 보기. 한 작품 편집 패널에서 상태, 회차, 날짜, 메모, 개인 태그, 공개 범위를 편집한다.

`서재 공개`와 `평가 공개`를 각각 설명한다. 메모와 회차는 항상 비공개임을 표시한다. 다중 선택으로 상태 변경, 태그 추가, 공개 범위 변경, 삭제를 지원한다. 대량 요청은 최대 100개 단위로 제한하고 부분 성공을 숨기지 않는다.

### 리뷰와 글 작성

제목이 필요한 커뮤니티 글과 작품에 연결된 리뷰를 구분한다. 리뷰에는 본문, 스포일러 전체 표시, 읽은 기준 회차를 입력한다. 현재 리뷰는 수동 저장 확인 후 저장된 초안을 별도 게시한다. 자동 초안 저장은 아직 구현하지 않았다. 글에는 카테고리와 관련 작품 최대 5개를 입력하며 P5에서 초안 저장과 게시를 분리해 연결한다.

게시 전 `이 내용은 공개됩니다`와 스포일러 선택을 확인한다. 오류가 발생해도 입력을 지우지 않는다. 삭제 시 댓글이 함께 접근 불가해짐을 안내한다.

### 티어 편집기

상단: 제목, 설명, 공개 상태, 마지막 저장 시각, 실행 취소/다시 실행, 미리보기, 게시. 데스크톱 왼쪽 패널: 작품 검색/내 서재와 추가 가능한 작품. 가운데: 티어 행. 하단: 미배치함.

모바일은 작품 추가를 바텀시트로 열고 `S로 이동`, `위로`, `아래로`, `미배치로` 메뉴를 제공한다. 드래그만으로 기능을 수행하게 만들지 않는다. 긴 제목도 잘리지 않은 접근성 이름을 제공한다.

저장 상태는 `변경 사항 없음`, `저장 중`, `저장 완료 23:10`, `오프라인: 이 기기에 임시 보관`, `저장 실패: 다시 시도`, `다른 화면에서 변경됨`을 구분한다. 오프라인 임시 보관을 서버 저장 완료라고 표시하지 않는다.

충돌창은 서버 최신 버전과 현재 편집본의 시각을 보여주고 `서버 버전 불러오기` 또는 `내 편집본을 새 티어표로 저장`을 제공한다. 다른 탭 변경을 자동으로 덮어쓰지 않는다.

기본 티어 가져오기는 개인 평가를 읽어 초안에 넣는다. 반대 방향은 명시적 반영 버튼만 사용한다. 한 표에 같은 작품을 두 번 놓을 수 없다.

### 티어 게시본과 공유

작성자, 게시 시각, 버전, 설명, 행과 작품, 좋아요/댓글, 프로필, 내 표로 복제를 제공한다. 링크 공개 표는 탐색/피드/프로필에서 빠지고, 이번 버전에서는 좋아요와 댓글도 비활성화한다. URL을 가진 사람이 읽고 복제하는 것만 허용한다.

공개 URL에는 현재 게시본이 나온다. 초안을 변경하는 동안 기존 게시본은 유지된다. `게시본 업데이트` 후 내용이 바뀌며, 삭제/비공개 전환 시 익명 접근이 차단된다.

PNG 저장은 실제 전체 표를 여러 페이지로 내보내며, OG 미리보기는 고정 비율의 축약 카드다. 둘을 같은 이미지로 취급하지 않는다. 허가 범위가 화면 표시만 허용하면 PNG/OG에서는 텍스트 카드로 대체한다.

### 프로필과 비교

프로필: 기본 정보, 팔로우/차단/신고, 공개 독서 수, 공개 평가 수, 공개 장르 분포, 대표 티어표, 리뷰. 소유자가 보는 전체 기록과 방문자가 보는 공개 기록을 명확히 구분한다. 대표 티어표는 현재 공개 상태인 본인 표만 선택할 수 있다.

비교: 로그인 사용자 자신이 열람 가능한 평가와 상대의 공개 평가만 사용한다. 공통 작품 수, 점수, 신뢰도 안내, 둘 다 S인 작품, 차이가 큰 작품, 장르 공통점을 표시한다. 공통 비교 가능 작품이 5개 미만이면 숫자 점수를 숨긴다. 이 비교 화면의 결과는 다른 사람에게 공개하는 공유 기능을 만들지 않는다.

### 커뮤니티와 알림

목록은 카테고리, 최신/인기, 관련 작품 필터를 제공한다. 댓글 답글은 한 단계만 허용한다. 좋아요 버튼에 중복 요청 중 표시와 실패 시 원복을 구현한다.

알림에는 본문 원문을 저장하지 않는다. 알림 열람 시 대상이 삭제/비공개/차단되었는지 다시 확인하고 `더 이상 볼 수 없는 콘텐츠`로 표시한다. 알림 설정에서 종류별 수신을 끌 수 있다.

### 운영자 화면

신고 상세에 신고 대상, 사유, 접수/처리 시각, 권한 범위 내 원문, 조치 이력을 보여준다. 숨김/복구에는 사유가 필수다. 단순 신고 누적만으로 자동 삭제하지 않는다. 작품 등록에서 실제 API 연동이 없는 플랫폼의 연동 성공 표시를 만들지 않는다.

## 5. 대표 사용자 흐름

**첫 가입:** 회원가입 → 메일 확인 → 사용자 확인 동작 → 인증 성공 → 온보딩 → 좋아하는 장르 선택/건너뛰기 → 작품 검색 → 서재 저장. 이메일/소셜 인증과 앱 동의 상태를 각각 검증한다.

**평가:** 작품 상세 → 읽기 상태 선택 → 별점 또는 기본 티어 → 공개 범위 확인 → 서버 저장 → 같은 작품을 서재에서 열어 값 확인. 상태/평가를 함께 저장할 때 중간 불일치가 없어야 한다.

**티어 공유:** 표 생성 → 작품 추가 → 배치 → 초안 저장 확인 → 게시 미리보기 → 공개 범위 선택 → 게시 → URL 복사 → 시크릿 창에서 게시본 확인.

**다른 독자 발견:** 공개 티어 열람 → 작성자 프로필 → 내 취향과 비교 → 팔로우 → 팔로잉 피드에서 이후 공개 게시 확인.

**권리 철회:** 관리자 자산 검색 → 허가 철회 → 화면/PNG/OG 신규 요청에서 텍스트 커버로 대체 → 캐시 만료 확인 → 운영 기록 저장.

**탈퇴:** 영향 범위 확인 → 최근 재인증 → 탈퇴 확정 → 즉시 로그인/공개 노출 제한 → 삭제 작업 상태 확인. 서버 처리 중 오류가 나도 계정을 다시 공개하지 않는다.

## 6. 공통 상태와 접근성

모든 데이터 화면에서 loading, empty, success, error, forbidden 또는 not-found를 설계한다. 타인의 비공개 데이터는 존재 여부가 드러나지 않도록 동일한 not-found 응답을 우선한다.

폼 오류는 입력 옆과 폼 요약에서 확인 가능해야 하며 첫 오류로 포커스를 이동한다. 모달은 포커스를 가두고 닫힌 후 원래 버튼으로 돌린다. 저장/배치 결과는 aria-live로 알린다. 색상만으로 티어, 오류, 공개 상태를 구분하지 않는다.

터치 대상은 제품 기준 최소 44px를 목표로 한다. 360px, 768px, 1280px 뷰포트를 검수하고 본문 가로 스크롤을 허용하지 않는다. 표 편집 캔버스의 의도된 스크롤은 별도 안내한다. reduced-motion을 존중한다.

## 7. 메타데이터와 검색 노출

공개 작품, 공개 글, 공개 리뷰, 공개 티어, 공개 프로필만 정식 canonical을 가진다. sitemap에는 현재 접근 가능한 공개 항목만 포함한다. 비공개 전환/삭제 시 제거한다.

스포일러 리뷰는 OG 설명, 목록 발췌, 구조화 데이터, 초기 SSR/클라이언트 payload에 본문을 넣지 않는다. 본문 펼치기 후 별도 요청으로 불러온다. 스포일러 표시 자체는 접근 권한 보호가 아니라 제품상 노출 제어임을 구분한다.

링크 전용 공유는 `noindex, nofollow`, `Referrer-Policy: no-referrer`, 분석 로그 토큰 마스킹을 적용한다. 링크 전용 OG는 작품명 없이 일반 서비스 카드만 제공한다. noindex는 보안 수단이 아니며 토큰 검증은 별도로 필요하다.

색상 토큰은 잉크 #272538, 종이 #FAFAFD, 아이리스 #5747BE, 라일락 #DAD3FA, 민트 #C5E4D6, 피치 #F3D4C0을 중심으로 구성한다. 브랜드/제목에는 설치된 Avenir Next와 한국어 시스템 폰트, 본문에는 시스템 고딕을 사용한다. 폰트 파일을 다운로드하거나 재배포하지 않는다. 세 권의 타이포그래피 책은 서비스 개념을 설명하는 직접 만든 CSS 일러스트이며 작품 데이터가 아니다.

1280px 최대 너비, 360/768/1280px 레이아웃, 라이트/다크/시스템 테마, skip link와 포커스, 모바일 하단 메뉴, 오류/로딩/빈 상태 공통 컴포넌트를 구성했다. 홈 외에 explore/tiers/community/me/library/settings/profile/auth/sign-in은 준비 중 화면만 제공한다. P0 전체는 noindex다. 실제 권한 보호나 회원 기능을 구현한 것으로 해석하지 않는다.
